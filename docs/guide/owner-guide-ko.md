# COMS PC Guard 사용 안내서

동아리방 PC에서 **정해진 시간에, 등록한 부원 계정이, 등록한 게임을 못 켜게** 막는 프로그램입니다.
관리자(이 안내서에서는 "관리자"라고 부릅니다)는 언제든 잠깐 허용하거나, 바로 전부 막거나, 시간표를 바꿀 수 있어요.

- 막는 일은 Windows에 들어 있는 **AppLocker(앱 실행 제한 기능)** 가 합니다. 이 프로그램은 그 규칙을 시간표에 맞춰 바꿔 줄 뿐이라, 프로그램이 잠깐 멈춰도 마지막 규칙은 Windows에 그대로 남아요.
- 화면, 키보드, 인터넷 사용 내용은 **보지 않습니다**. "누가, 언제, 어떤 게임을 켜려다 막혔는지"와 설정 변경만 **30일 동안** 기록해요.

---

## 1. 준비

| 필요한 것 | 설명 |
|---|---|
| Windows 11 PC | 기업용(Enterprise) Windows 11에서 시험을 마쳤어요. Microsoft 안내로는 2023년 업데이트(KB5024351) 이후 모든 Windows 11에서 이 기능이 동작하지만, Pro·Home에서는 아직 직접 시험하지 않았어요. |
| 관리자 계정 1개 | 설치하고 설정을 바꾸는 계정이에요. **비밀번호는 관리자만 알아야 해요.** |
| 부원 계정 | 부원은 각자 **표준 사용자(관리자 아님)** 계정으로 로그인해야 해요. 관리자 권한이 있는 계정은 이 프로그램을 끌 수 있어서 막을 수 없어요. |

---

## 2. 설치

1. 받은 압축 파일을 풀거나, 배포 폴더를 PC로 통째로 복사해요.
2. 폴더 안의 **`install.cmd`를 더블클릭**해요.
3. "이 앱이 디바이스를 변경하도록 허용하시겠어요?"에서 **예**를 눌러요.
4. 검은 창에 "설치를 마쳤어요."가 나오면 아무 키나 눌러 닫아요.

설치가 끝나면:

- 바탕 화면과 시작 메뉴에 **"COMS PC Guard 관리"** 바로 가기가 생겨요.
- **설치한 계정이 관리자**가 되고, 기본 설정(매일 09:00~18:00 제한)이 만들어져요.
- 처음에는 **"시험 운영" 모드**예요. 이 모드에서는 막지 않고, 막았을 실행만 기록해요.
- 부원 계정에는 다음 로그인부터 화면 오른쪽 아래에 **방패 아이콘**(내 상태 알림)이 생겨요.

> 다른 계정을 관리자로 하고 싶다면, 관리자 PowerShell에서
> `.\Install-ComsPcGuard.ps1 -Owner 계정이름` 으로 설치해요.

---

## 3. 처음 설정하기 (관리 화면)

바탕 화면의 **"COMS PC Guard 관리"** 를 더블클릭해요(관리자 권한을 물으면 "예").

### ① 부원 등록 — "부원" 탭
1. "계정" 칸에서 부원 계정을 고르거나 계정 이름을 적어요.
2. **부원 추가**를 눌러요.

### ② 게임 등록 — "게임" 탭
1. **실행 파일 골라서 추가…** 를 눌러요.
2. 게임 설치 폴더에서 게임 실행 파일(.exe)을 골라요.
   - 게임 회사의 **서명**으로 등록하기 때문에, 게임이 업데이트되거나 파일 이름이 바뀌어도 계속 알아봐요.
   - 서명이 없는 파일은 등록할 수 없어요. 그럴 때는 같은 폴더의 다른 실행 파일(보통 게임 이름으로 된 파일)을 골라 보세요.
   - 런처(게임 실행기)와 게임 본체가 따로 있으면 둘 다 등록하는 게 좋아요.
3. "표시 이름"은 비워 두면 게임 이름이 자동으로 들어가요.

### ③ 시간표 — "시간표" 탭
1. 제한할 요일에 체크하고, 시작·끝 시각을 정해요(하루 종일이면 "하루 종일" 체크).
2. **시간표 저장**을 눌러요.
3. 방학·행사 날처럼 제한하지 않을 날은 아래에서 날짜를 고르고 **쉬는 날 추가**를 눌러요.

### ④ 며칠 지켜보기 — "기록" 탭
시험 운영 모드에서 부원이 제한 시간에 게임을 켜면 "막았을 실행"으로 기록돼요.
제대로 잡히는지, 엉뚱한 프로그램이 잡히지 않는지 며칠 확인해요.

### ⑤ 실제로 막기 — "상태" 탭
**차단 모드**에 체크하면 그때부터 실제로 막아요.

---

## 4. 평소 운영

| 하고 싶은 일 | 관리 화면에서 |
|---|---|
| 잠깐 게임 허용 | "잠깐 허용" 탭 → 누구 / 게임 / 얼마나(30분·1시간·2시간·오늘 끝까지) → **잠깐 허용**. 시간이 지나면 저절로 다시 막혀요. |
| 허용 취소 | "잠깐 허용" 탭 → 목록에서 골라 **선택한 허용 취소** (또는 **모두 취소**) |
| 지금 바로 전부 막기 | "상태" 탭 → **긴급 제한** 체크. 시간표·잠깐 허용과 상관없이 막아요. 풀 때는 체크 해제. |
| 시험 운영으로 되돌리기 | "상태" 탭 → **차단 모드** 체크 해제 |
| 부원이 지금 어떤 상태인지 보기 | "상태" 탭 아래 목록 |

**제한 시간이 시작될 때 이미 켜져 있던 게임은** 부원 화면에 경고 창이 뜨고 **15초 뒤에 꺼져요.** 저장하지 않은 내용은 사라질 수 있으니, 부원들에게 미리 알려 주세요.

**부원 화면의 방패 아이콘**은 자기 상태만 보여 줘요(설정은 바꿀 수 없어요).
- 아이콘을 더블클릭하면 게임별로 "사용할 수 있어요 / 지금은 제한 시간이에요 (18:00까지)"가 보여요.
- 제한이 시작되기 5분 전, 잠깐 허용이 끝나기 5분 전에 알림이 떠요.

바꾼 설정은 **몇 초 안에** 적용돼요. 관리 화면 "상태" 탭에서 "서비스가 설정 N번을 적용하고 있어요"의 번호가 맨 위 "설정 N번"과 같으면 적용된 거예요.

---

## 5. 기록 보기와 내보내기

"기록" 탭에서 최근 1일·7일·30일 기록을 볼 수 있어요. 기록되는 것:

| 종류 | 뜻 |
|---|---|
| 실행 막음 | 부원이 제한 시간에 게임을 켜려다 막혔어요. |
| 막았을 실행 | 시험 운영 중이라 막지 않았지만, 차단 모드였다면 막혔을 실행이에요. |
| 종료 경고 / 게임 종료 | 제한 시간이 시작될 때 켜져 있던 게임에 경고를 보냈거나 껐어요. |
| 설정 변경 | 관리 화면이나 명령어로 설정을 바꿨어요(누가 바꿨는지 함께 남아요). |
| 규칙 적용 / 적용 문제 | 서비스가 규칙을 적용했거나, 적용하지 못한 이유예요. |

**엑셀용 파일로 저장…** 을 누르면 엑셀·한셀에서 바로 열 수 있는 파일(.csv)로 저장돼요.
기록은 30일이 지나면 자동으로 지워져요.

## 6. 명령어로 하기 (선택)

관리 화면 대신 명령어로도 모든 설정을 할 수 있어요. **관리자 권한으로 연 PowerShell**에서 실행해요.
프로그램 위치는 `C:\Program Files\ComsPcGuard\guard.exe` 예요.

| 명령어 | 하는 일 |
|---|---|
| `guard member add 계정` / `remove 이름` / `list` | 부원 등록·빼기·목록 |
| `guard app add "게임.exe 경로"` / `remove 이름` / `list` | 게임 등록·빼기·목록 |
| `guard schedule set 평일 09:00 18:00` | 시간표 (요일 예: 매일, 평일, 주말, 월-금, 토,일) |
| `guard schedule allday 주말` / `clear` | 하루 종일 제한 / 시간표 지우기 |
| `guard holiday add 2026-12-25` / `remove 날짜` | 쉬는 날 추가·지우기 |
| `guard grant 부원 게임 90` | 잠깐 허용 (90분. `2h`, `today`도 가능. 모든 부원·게임은 `all`) |
| `guard revoke all` | 잠깐 허용 모두 취소 |
| `guard emergency on` / `off` | 긴급 제한 켜기·끄기 |
| `guard mode enforce` / `audit` | 차단 모드 / 시험 운영 |
| `guard policy` | 지금 설정 보기 |
| `guard status` | Windows에 실제로 적용된 상태 보기(아무것도 바꾸지 않음) |
| `guard log` / `guard log export 파일.csv` | 기록 보기 / 파일로 저장 |

## 7. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 관리 화면 맨 위에 빨간 글씨로 "볼 수만 있어요" | 설치한 관리자 계정으로 로그인해서 열어요. 다른 관리자 계정으로는 설정을 바꿀 수 없어요. |
| "서비스가 3분 넘게 소식이 없어요" | PC를 다시 시작하거나, 관리자 PowerShell에서 `Restart-Service ComsPcGuard` 를 실행해요. |
| 상태가 "적용 보류" | 학교·회사에서 관리하는 다른 AppLocker 정책이 있으면 덮어쓰지 않고 멈춰요. 그 정책을 관리하는 사람과 먼저 이야기해야 해요. |
| 게임이 안 막혀요 | ① "시험 운영" 모드인지 확인 ② 부원 계정이 관리자 권한이 없는 표준 사용자인지 확인 ③ "게임" 탭에 그 게임의 실행 파일이 등록됐는지 확인(런처와 게임 본체가 다를 수 있어요) |
| 막으면 안 되는 프로그램이 막혀요 | "게임" 탭에서 그 항목을 빼요. 몇 초 안에 풀려요. 급하면 "긴급 제한"이 꺼져 있는지 보고, "잠깐 허용"을 써요. |
| 정책 파일이 망가졌어요 | 저장할 때마다 바로 전 설정을 `.bak`으로 남겨 두고, 망가지면 자동으로 그걸 써요. "기록" 탭에 "적용 문제"로 남아요. |

---

## 8. 지우기

폴더의 **`uninstall.cmd`를 더블클릭**하고 "예"를 눌러요.
막는 규칙도 함께 풀리고, 알림 아이콘과 바로 가기도 지워져요.
설정과 기록은 남겨 둬요. 다시 설치하면 그대로 이어져요. 설정과 기록까지 지우려면 관리자 PowerShell에서
`.\Uninstall-ComsPcGuard.ps1 -RemoveData` 를 실행해요.

---

## 9. 꼭 알아 둘 점

- **관리자 비밀번호를 아는 사람은 언제든 끌 수 있어요.** 이 프로그램은 표준 사용자 부원을 막는 도구예요.
- 회사 서명이 없는 게임, 웹 브라우저로 하는 게임, 휴대폰은 막지 못해요.
- 게임 회사가 서명하는 회사 이름을 바꾸면 그 게임을 다시 등록해야 해요("기록"에 막힌 기록이 안 남으면 의심해 보세요).
- 설치 폴더는 약 400MB예요(프로그램마다 실행에 필요한 파일이 들어 있어서 그래요).
- 시각은 한국 시간 기준이에요.
